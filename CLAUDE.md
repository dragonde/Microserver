# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

"Simplemente un Microservidor NodeJS" — a minimal Node.js HTTP server built from scratch (no framework), with its own request router and handler dispatch. The oldest repo in this account (Oct 2014).

## Layout

- `server.js` — server bootstrap.
- `router.js` — simple path-based routing.
- `requesthandlers.js` — request handler functions.
- `index.js` — entry point wiring the above together.
